We also implemented five test queries utilizing the operations we implemented, each query uses two or more tables and uses a composition of relational algebra operations to output a final relation table as result in the Driver.java file. The Driver.java file also contains relations schemas for all tables in the uni_in_class database, where anyone attempting to run the code can simply replace the path string with their own to run it.
