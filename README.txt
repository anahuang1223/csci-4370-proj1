Members: Sach Shrestha, Leen Quazi, Leanne Wong, Ana Huang, and Travis Burton

## About: 

In this project we implemented Relational Algebra operations in Java using the starter code and classes given to us. The operations we implemented were: project, select, union, diff, intersect, rename, cartesian product, natural join, and theta join in the RAImpl.java file. We also implemented five test queries utilizing the operations we implemented, each query uses two or more tables and uses a composition of relational algebra operations to output a final relation table as result in the Driver.java file. The relevant csv files containing all the tables in the uni_in_class database are placed inside the mysql-files folder.
